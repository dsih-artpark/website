# Disease Dashboard

Disease Dashboard is a flexible framework to quickly create interactive disease dashboards. It can be used for any disease and any geography, providing dynamic charts, maps, and trend analysis. Designed for ease of use and reproducibility, it helps researchers, policymakers, and public health teams explore disease data and insights efficiently.
