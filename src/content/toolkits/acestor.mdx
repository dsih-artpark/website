# Acestor

This is a Python-based framework for multi-model, multi-time-series disease outbreak forecasting. It provides a reproducible modelling pipeline, allowing users to run, compare, and ensemble multiple forecast models efficiently. Designed for flexibility, Acestor supports data preprocessing, model training, evaluation, and ensemble forecasting, making it a comprehensive tool for outbreak prediction
